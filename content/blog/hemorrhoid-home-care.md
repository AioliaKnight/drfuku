# 痔瘡在家怎麼顧？阿福醫師的清潔、用藥、坐浴居家照護全指南

## 前言：照護做對，比止痛藥更重要

「醫師，我每天都在擦藥，為什麼痔瘡還是反覆發作？」在門診中，這是我最常聽到的困擾。

我是大腸直腸外科的阿福醫師。根據臨床研究統計，**約 80% 的初期痔瘡（第一、二級）患者，透過正確的居家照護與飲食調整，症狀可以得到顯著緩解，甚至不需要手術治療。** 

居家照護不是隨便塗塗抹抹，它有一套嚴謹的 SOP。只要掌握「清潔、用藥、坐浴、飲食、習慣」這五大核心，您就能掌握自己健康的發言權。

## 一、專業清潔 SOP：讓患部安靜的基本功

痔瘡發炎時，肛門周圍的皮膚會變得異常脆弱，錯誤的清潔會讓發炎加劇。

### 【清潔步驟】
1.  **水溫控制**：排便後使用約 37-40°C 的溫水沖洗。切記「水壓不可過強」，以免刺激傷口。
2.  **避免洗劑**：發炎期間，請改用「清水」即可。避免使用含有香料、去角質成分或皂鹼的清潔產品，以免過度帶走皮脂造成搔癢。
3.  **輕拍拭乾**：這是最關鍵的一步。**絕對不要用衛生紙來回摩擦**，應使用柔軟毛巾輕拍（Dabbing）吸乾，或使用吹風機「冷風」距離 15 公分輕吹至乾。
4.  **透氣第一**：穿著純棉、寬鬆的內褲，避免人造纖維造成的悶熱潮濕。

> 💡 **阿福醫師叮嚀**：有些患者因為怕不乾淨，會用濕紙巾用力擦，結果濕紙巾裡的防腐劑和摩擦力反而引發嚴重的「刺激性皮膚炎」，痛上加痛。

## 二、用藥 SOP：薄塗才是硬道理

藥膏不是塗越多越好，正確的給藥方式才能讓有效成分深達患部。

### 【給藥技巧】
-   **外用藥膏**：洗淨並吸乾患部後，擠出約一個米粒大小，薄薄一層塗抹於患部。量太多會造成局部皮膚悶熱，反而容易滋生細菌。
-   **塞劑使用**：建議在坐浴後或睡前使用。放入肛門約一個指節深度後，**請平躺 10-15 分鐘**，讓塞劑完全融化吸收，避免立刻下床走動。
-   **頻率掌握**：嚴格遵照醫囑，通常為早晚各一次。若症狀在 3-5 天內無明顯改善，請務必回診，切勿自行長期使用含有類固醇的藥膏。

## 三、溫水坐浴 SOP：物理治療的黃金標準

溫水坐浴能放鬆括約肌，改善血液循環，對緩解疼痛與消腫有奇效。

| 項目 | 專業建議 |
| :--- | :--- |
| **次數** | 每天 3-4 次，特別建議在「排便後」及「洗澡後」。 |
| **時間** | 每次 10-15 分鐘。時間太久（超過 20 分鐘）反而會讓局部血管擴張過度。 |
| **容器** | 建議使用專用的坐浴盆，放置在馬桶上，姿勢較為輕鬆。 |
| **溫度** | 37-40°C（體感微溫即可，不可燙手）。 |
| **添加物** | **建議只用純水**。除非醫師指示，否則不建議隨意添加鹽巴、精油或藥草，以免過敏。 |

## 四、細緻飲食與水分清單：把便便變得柔軟

排便的力量是痔瘡最大的敵人。我們要透過飲食，讓糞便像「熟透的香蕉」一樣滑順。

### 【高纖食物推薦表】
| 類別 | 推薦食材（每 100g 纖維含量） |
| :--- | :--- |
| **全穀類** | 燕麥 (10g)、地瓜 (2.4g)、糙米 (2.3g) |
| **蔬菜類** | 木耳 (7.4g)、花椰菜 (3g)、地瓜葉 (3.3g) |
| **水果類** | 奇異果 (3g)、百香果 (5.3g)、芭樂 (5g) |
| **油脂類** | 橄欖油、亞麻仁油、適量堅果（潤滑腸道） |

-   **水分數據**：每天飲水量應達 `體重 (kg) x 30-35 cc`。如果您體重 60 公斤，每天至少要喝 1800-2100 cc。
-   **專業警訊**：若開始增加纖維攝取，**一定要同時增加飲水量**，否則纖維會吸乾腸道水分，反而導致更嚴重的便秘。

## 五、生活習慣與警訊判斷

### 【醫師建議的日常微調】
-   **如廁時長**：嚴禁邊上廁所邊滑手機，如廁時間應控制在 **5 分鐘內**。
-   **如廁姿勢**：腳下墊一個約 15-20 公分的小板凳，讓身體呈 35 度前傾，可以放鬆恥骨直腸肌，排便更輕鬆。
-   **久坐對策**：每 50 分鐘起身活動 5 分鐘。避免坐在過硬的椅子上，建議使用中空的甜甜圈坐墊減少直接壓迫。

### 【專業警訊判斷：何時該立刻就醫？】
若出現以下狀況，代表居家照護已不足夠，需專科醫師介入：
1.  **出血量增加**：鮮血滴落馬桶或伴隨血塊。
2.  **疼痛分級上升**：VAS 疼痛分數超過 7 分（影響睡眠或行動），且止痛藥無效。
3.  **痔核嵌頓**：痔瘡脫出後完全無法推回，且顏色轉為紫黑色（可能為壞死風險）。
4.  **發燒畏寒**：肛門周圍紅腫熱痛並伴隨發燒，需排除肛門膿瘍感染。

## 常見問題 FAQ

**Q：痔瘡自己會好嗎？**
**A：** 輕微的一、二度痔瘡（只有偶爾出血或輕微脫出）透過上述居家照護 SOP，症狀是可以完全消失進入「緩解期」的。但痔瘡是血管組織的退化，若生活習慣沒改，仍會再次復發。

**Q：坐浴一定要用溫水嗎？可以冷敷嗎？**
**A：** 急性發作、腫脹劇烈的前 24 小時可以適度冷敷消腫；但長期照護仍建議溫水坐浴，效果在於「放鬆肌肉」與「促進血流」，這是冷敷做不到的。

**Q：孕婦痔瘡發作怎麼辦？**
**A：** 孕婦因腹壓大，最適合這套居家照護。坐浴對孕婦非常安全，但用藥前請務必諮詢婦產科與大腸直腸外科醫師。
